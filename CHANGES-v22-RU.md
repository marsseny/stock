# Изменения v22 (nuovamotion) — правки дизайна

## 1. Первый экран
- Левый блок с поиском стал примерно на четверть уже и примерно на 20% ниже.
- Заголовок меньше; после «Premium» перенос строки. «Premium» — плотный жирный гротеск, «Video Templates» —
  курсивная антиква внутри полупрозрачной стеклянной капсулы (как в референсе «I was created to *create*»).
- Правый блок переделан: одно крупное превью топ-проекта, под ним два ряда небольших широких баннеров (5 × 2) без подписей.
  Клик по баннеру меняет крупное превью. Превью само переключается каждые 7 секунд и останавливается, пока на блок наведён курсор.
  На телефоне баннеры листаются вбок в два ряда.

## 2. Логотип
- Новый знак: чёрная скруглённая плитка с тонкой светлой кромкой и жирной мягкой, чуть размытой буквой «n» в молочно-белом
  градиенте с бликом. Тот же знак — в `favicon.svg`.
- Надпись «**nuova**motion» с маленькой буквы, слитно: «nuova» — жирным, «motion» — обычным.

## 3. Превью проектов
- Затемнение при наведении теперь только на нижней четверти превью (было — нижняя половина).
- Убрано лёгкое поднятие превью вверх при наведении.
- Скругление углов у всех превью уменьшено (20 → 10 px), отступы между превью в сетке уменьшены (24 → 14 px).
- «All projects» на главной по умолчанию показывает в 1,5 раза больше проектов (27 вместо 18); «Load more» добавляет ещё по 27.

## 4. Страница проекта
- Строка с оценкой и отзывами показывается, только если у проекта 3 отзыва и больше.
- Блоки описания стали строже: почти чёрные карточки с тонкой светлой рамкой, мелкие серые подписи, тонкий шрифт,
  разделительная линия, без ярких цветных подложек. Иконки — монохромные тонкие линии без рамок вокруг
  (в том числе «Ae» / «Pr» — просто буквы без квадрата). Анимации в карточках перерисованы светлыми линиями.

## Что не менялось
Покупка, промокоды, аккаунт, отзывы, скачивание, сервер `/api/*` и настройки Cloudflare Pages — без изменений.

## Как выкатить
Загрузите содержимое архива в репозиторий и дождитесь нового деплоя на Cloudflare Pages. Менять настройки
сборки и переменные окружения не нужно.
