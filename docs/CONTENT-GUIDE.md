# Как подготовить проект к публикации на Nuova Motion

Эта инструкция описывает, какие файлы и данные нужно собрать для **каждого** проекта (шаблона, пресета, пака), чтобы его можно было опубликовать на сайте. Готовые шаблоны данных лежат рядом:

- `docs/product-template.json` — один проект в формате JSON (именно такой формат использует сайт);
- `docs/products-template.csv` — та же структура в виде таблицы. Удобно заполнять в Google Sheets / Excel сразу для многих проектов.

---

## 1. Структура папки проекта

Для каждого проекта соберите одну папку, названную его `slug` (латиница, строчные буквы, слова через дефис):

```
liquid-hud-elements-bundle/
├── poster.jpg            ← фотопревью (обложка), 1920×1080
├── preview-720.mp4       ← видеопревью для карточек каталога
├── preview-1080.mp4      ← (необязательно) видеопревью для страницы товара
├── data.json             ← описание, теги, характеристики (по шаблону)
└── liquid-hud-elements-bundle_v1.0.zip   ← файл, который получает покупатель
```

---

## 2. Фотопревью (обложка / poster)

Обложка показывается, пока видео не загрузилось, и в корзине. На сайте все превью имеют пропорции **16:9**.

| Параметр | Значение |
|---|---|
| Размер | **1920×1080 px** (16:9). Меньше 1600×900 не делайте |
| Формат | JPG (качество 80–85%) или WebP |
| Вес | до **400 КБ** |
| Цветовой профиль | sRGB |
| Содержимое | лучший кадр из видеопревью. Без рамок, без кнопок «Play», без водяных знаков поверх главного объекта |
| Безопасная зона | в левом верхнем углу сайт выводит бейджи (AE, Pack · 140 items), в правом нижнем — кнопку звука. Не ставьте туда важный текст: отступ ~8% от краёв |

Сайт сам уменьшает обложку под нужный размер экрана через CDN хостинга (Cloudflare). Поэтому достаточно одного файла в 1920×1080, отдельные миниатюры не нужны.

**Где хранить:** обложки лёгкие, их удобно хранить прямо в проекте: `public/media/<slug>/poster.jpg`. Адрес на сайте будет `/media/<slug>/poster.jpg`.

## 3. Видеопревью

### Параметры файла

Видео играет при наведении на карточку и автоматически на странице проекта (там есть таймлайн и кнопка play/pause), по кругу. Звук включается кнопкой с иконкой динамика; выбор посетителя (звук вкл/выкл) запоминается для всех видео на сайте до конца визита.

| Параметр | Для карточек (`preview-720.mp4`) | Для страницы товара (`preview-1080.mp4`, по желанию) |
|---|---|---|
| Разрешение | 1280×720 | 1920×1080 |
| Пропорции | 16:9. Вертикальные шаблоны разместите по центру кадра 16:9 на фоне | 16:9 |
| Кодек | **H.264 (MP4)**, профиль High | H.264 (MP4) |
| Битрейт | 2–3 Мбит/с | 4–6 Мбит/с |
| Частота кадров | 25 или 30 fps | 25 или 30 fps |
| Длительность | **10–30 секунд**, бесшовная петля | до 60 секунд |
| Звук | AAC 128 кбит/с (или без звука) | AAC 128–192 кбит/с |
| Вес | до **6–8 МБ** | до 25 МБ |
| Обязательно | флаг **faststart**, чтобы видео начинало играть сразу | faststart |

Первые 1–2 секунды должны быть самыми эффектными: посетитель решает, смотреть ли дальше, почти мгновенно.

Видео можно сжать бесплатной программой **HandBrake** (пресет «Fast 720p30», галочка «Web Optimized»). Или одной командой **ffmpeg**:

```bash
# превью для карточек 720p
ffmpeg -i master.mov -vf "scale=1280:720:flags=lanczos" -c:v libx264 -profile:v high -preset slow \
  -b:v 2500k -maxrate 3000k -bufsize 5000k -pix_fmt yuv420p -r 30 \
  -c:a aac -b:a 128k -movflags +faststart preview-720.mp4

# превью для страницы товара 1080p
ffmpeg -i master.mov -vf "scale=1920:1080:flags=lanczos" -c:v libx264 -profile:v high -preset slow \
  -b:v 5000k -maxrate 6000k -bufsize 10000k -pix_fmt yuv420p -r 30 \
  -c:a aac -b:a 160k -movflags +faststart preview-1080.mp4
```

### Где хранить видео: рекомендация

Нужен **CDN, который отдаёт сам MP4-файл по прямой ссылке**. Тогда сайт показывает видео своим встроенным плеером: без логотипов, рекламы, «похожих видео» и лишних кнопок. YouTube и Vimeo для этого не подходят: они встраиваются только со своим плеером и брендингом, а прямой файл у Vimeo есть только на дорогих тарифах.

| Вариант | Цена (ориентировочно, проверьте на сайте сервиса) | Плюсы | Минусы |
|---|---|---|---|
| **⭐ Bunny.net Storage + CDN** (рекомендуем) | хранение ≈ $0.01/ГБ в месяц, раздача ≈ $0.005–0.01/ГБ, минимальный платёж около $1 в месяц | очень быстрый CDN по всему миру, прямые ссылки на MP4, простая загрузка через веб-интерфейс или FTP | нужна регистрация и карта |
| **Cloudflare R2** | хранение $0.015/ГБ в месяц, **раздача бесплатно**, 10 ГБ бесплатно | нет платы за трафик, это выгодно при большом числе просмотров | чуть сложнее в настройке: нужно подключить свой домен к бакету |
| Хранить прямо на сайте (`public/`) | входит в тариф хостинга | ничего настраивать не нужно | видео расходуют трафик тарифа и раздуваются деплои. Подходит только для 5–10 первых проектов |

**Как залить на Bunny.net:**
1. Создайте **Storage Zone** (например, `nuovamotion-media`) и подключите к ней **Pull Zone**. Вы получите адрес вида `https://nuovamotion.b-cdn.net`.
2. Загрузите файлы в папку `previews/<slug>/`.
3. Ссылка на видео будет такой: `https://nuovamotion.b-cdn.net/previews/<slug>/preview-720.mp4`. Её вставляете в поле `preview.video`.
4. В настройках Pull Zone включите кэширование. Для защиты от «воровства» трафика включите **Hotlink protection** и разрешите только домен сайта.

Не используйте Bunny **Stream** (видеохостинг с плеером), нужен именно **Storage + CDN**: тогда отдаётся чистый файл.

## 4. Описание, теги, характеристики (шаблон данных)

Заполните `data.json` по образцу `docs/product-template.json` или строку в `docs/products-template.csv`. Тексты на сайте сейчас на английском, поэтому описание и теги пишите тоже на английском.

| Поле | Обязательно | Что писать | Пример |
|---|---|---|---|
| `slug` | да | адрес страницы: латиница, дефисы, уникальный | `liquid-hud-elements-bundle` |
| `title` | да | название, до ~40 символов | `Liquid HUD Elements Bundle` |
| `author` | да | автор / студия (на странице проекта не выводится) | `Your Studio` |
| `category` | да | одно из: `after-effects`, `premiere-pro`, `plugins`, `davinci-resolve`, `presets`, `sound-fx` | `after-effects` |
| `tier` | да | `basic`: обычный проект, `featured`: показывать в «Featured», `pack`: большой пак | `pack` |
| `tags` | да | 4–8 тегов, строчными буквами. Первые 4 видны в карточке, по тегам работает поиск | `["hud","sci-fi","interface"]` |
| `price` | да | цена в долларах, целое число | `39` |
| `oldPrice` | нет | старая цена, если есть скидка | `59` |
| `itemsCount` | только для паков | сколько элементов внутри | `140` |
| `includes` | только для паков | 4–8 строк «что внутри» | `["40 HUD circles", …]` |
| `resolution` | да | `1920×1080`, `3840×2160 (4K)`, `1080×1920 (Vertical)` или `Resolution independent` | `3840×2160 (4K)` |
| `duration` | для видео-шаблонов | длительность в формате `м:сс` | `0:30` |
| `compatibility` | да | программа и минимальная версия | `After Effects 2022+` |
| `fileSize` | да | размер архива для скачивания | `4.2 GB` |
| `pluginsRequired` | да | нужны ли сторонние плагины (`true`/`false`). Если да, перечислите их в описании | `false` |
| `createdAt` | да | дата публикации, `ГГГГ-ММ-ДД` | `2026-11-12` |
| `specs` | нет | строки таблицы характеристик, см. раздел 4а. Удобнее заполнять в `product-specs.csv` | `[{"label":"Application","value":"After Effects 2022+"}]` |
| `description` | да | 2–4 предложения: что это, для чего, как легко редактировать, есть ли туториал | — |
| `preview.video` | да | прямая ссылка на MP4 (см. раздел 3) | `https://…/preview-720.mp4` |
| `preview.poster` | да | путь к обложке (см. раздел 2) | `/media/<slug>/poster.jpg` |
| `download.fileName` | да | имя архива для покупателя | `<slug>_v1.0.zip` |

**Советы по описанию:** первое предложение говорит, что это и сколько элементов. Второе — ключевые фичи (контроль цвета, drag-and-drop, 4K). Третье — что входит в комплект (туториал, шрифты, музыка). Не дублируйте в описании характеристики: они уже есть в таблице на странице товара.

## 4а. Строки характеристик на странице проекта (табличка `specs`)

Справа на странице проекта под кнопкой «Add to cart» выводится таблица характеристик («Application», «Resolution», «Duration», …). Для каждого проекта набор строк **свой**: вы сами решаете, какие строки показать, как они называются и в каком порядке идут.

Строки заполняются в одной общей таблице: **`src/data/product-specs.csv`**. Образец лежит в `docs/specs-template.csv`.

| Колонка | Что писать | Пример |
|---|---|---|
| `slug` | slug проекта, к которому относится строка (точно как в адресе `/item/<slug>`) | `grain-slideshow` |
| `label` | название строки — левая колонка (на английском) | `Application` |
| `value` | значение — правая колонка | `After Effects CC 2020+` |

Правила:
- **Одна строка таблицы = одна строка характеристик.** Для проекта с 6 характеристиками будет 6 строк с одинаковым `slug`.
- Строки показываются на сайте **в том порядке, в котором стоят в таблице**.
- Названия можно придумывать любые: `Placeholders`, `Fonts`, `Tutorial`, `Music`, `Items` и т. д.
- Если для проекта в таблице нет ни одной строки, сайт покажет стандартный набор (Application, Resolution, Duration, File size, Plugins required, Released), собранный из полей `data.json`.
- Пустые ячейки `label`/`value` пропускаются.

Как заполнять удобнее всего:
1. Откройте `docs/specs-template.csv` в Google Sheets (*Файл → Импортировать*) или Excel.
2. Добавляйте строки для нового проекта под уже существующими. Первую строку с заголовками `slug,label,value` не меняйте.
3. Скачайте таблицу как CSV (*Файл → Скачать → CSV*) и замените им файл `src/data/product-specs.csv`.
   Подходят файлы с разделителем «,» (Google Sheets) и «;» (Excel с русской локалью). Значения с запятой внутри (`Jul 28, 2026`) таблица сама возьмёт в кавычки. В Excel сохраняйте как **«CSV UTF-8»**, иначе символы вроде «×» превратятся в кракозябры.

Пример:

```csv
slug,label,value
grain-slideshow,Application,After Effects CC 2020+
grain-slideshow,Resolution,1080×1920 (Vertical)
grain-slideshow,Duration,0:25
grain-slideshow,Placeholders,"18 media, 12 texts"
grain-slideshow,Plugins required,No
grain-slideshow,Released,"Jul 28, 2026"
```

## 5. Файл проекта для скачивания (выдаётся после покупки)

### Как упаковать архив
- Формат **ZIP**, имя `<slug>_v1.0.zip`. При обновлении проекта повышайте версию: `v1.1`.
- Внутри: папка проекта (`.aep` / `.prproj` / `.drp` / пресеты) с собранными файлами (After Effects: *File → Dependencies → Collect Files*). Ещё нужны папка `Footage`, а также `README.txt` или `Help.pdf` со ссылками на бесплатные шрифты и, если нужны, на плагины.
- Не кладите в архив коммерческие шрифты и музыку без лицензии на распространение.
- Проверьте архив: распакуйте его на другом компьютере и откройте проект. Не должно быть сообщений о «missing files».

### Где хранить и как выдавать по уникальной ссылке

Архивы весят до нескольких гигабайт. Их нельзя класть в открытый доступ: ссылка должна выдаваться **только покупателю**, быть уникальной и со сроком действия. Есть два пути.

**Вариант A: готовый сервис продаж (быстро, без программирования). Рекомендуем для старта.**
**Lemon Squeezy** (комиссия ≈ 5% + $0.50 с продажи) или **Paddle** / **Gumroad** / **Payhip**. Вы загружаете ZIP в сервис, он сам принимает оплату, считает налоги и отправляет покупателю письмо с персональной ссылкой на скачивание. Ссылка ограничена по сроку и числу скачиваний. На сайте кнопка «Купить» ведёт на страницу оплаты сервиса (checkout overlay). Ограничения: архив до ~5 ГБ, нужно уточнить, доступен ли сервис для вашей страны и банка.

**Вариант B: своё хранилище и своя оплата (дешевле на больших объёмах, нужна доработка сайта).**
1. Архивы хранятся в **приватном** бакете **Cloudflare R2**: трафик бесплатный, это важно для многогигабайтных паков. Подойдёт и приватная Storage Zone в Bunny.net с Token Authentication.
2. Оплата через Stripe (или другой эквайринг). После успешной оплаты серверная функция на Cloudflare Pages проверяет платёж и создаёт **подписанную ссылку** (presigned URL). Ссылка действует, например, 24 часа. Функция отправляет её покупателю письмом и показывает в личном кабинете.
3. Сам файл отдаётся напрямую из R2/Bunny, а не через сайт, поэтому размер архива не ограничен.

Этот вариант — следующий этап развития сайта (сейчас корзина работает без оплаты). Ко всем архивам можно сразу применить одинаковую схему: `downloads/<slug>/<slug>_v1.0.zip` в приватном бакете.

## 6. Чек-лист перед публикацией

- [ ] `poster.jpg`: 1920×1080, до 400 КБ, без текста в углах
- [ ] `preview-720.mp4`: H.264, 720p, 10–30 с, до 8 МБ, faststart, бесшовная петля
- [ ] видео загружено на CDN, прямая ссылка открывается в браузере и сразу играет
- [ ] `data.json` заполнен: slug уникальный, категория из списка, 4–8 тегов, цена
- [ ] строки характеристик добавлены в `src/data/product-specs.csv` (раздел 4а)
- [ ] ZIP проверен на другом компьютере, внутри README со шрифтами/плагинами
- [ ] ZIP загружен в сервис продаж (вариант A) или в приватный бакет (вариант B)
