# Подробное описание проекта — как заполнять

Под видео на странице проекта показывается блок описания:

1. **Сетка плиток** («бенто»): описание проекта в 2–3 предложения и функции. Важные функции — крупные плитки с иконкой, второстепенные — маленькие текстовые плашки.
2. **Что включено** — категории сцен с количеством (например, «Typography 50») и карусель фото‑превью сцен: 3 ряда, по 5 превью на экране, каждый ряд листается влево‑вправо.
3. **Теги** — мелко внизу.

Описание есть у всех проектов сразу: пока вы ничего не заполнили, сайт показывает стандартный текст. Чтобы отредактировать описание конкретного проекта, создайте файл:

```
src/data/details/<slug>.json
```

Скопируйте `docs/details-template.json`, переименуйте по `slug` проекта и поправьте. Пример готового файла: `src/data/details/grain-slideshow.json`.

**Правило:** всё, что вы написали в файле, заменяет стандартное. Всё, что не указали, остаётся стандартным. Поэтому файл может быть коротким — например, только `summary` и `included`.

---

## Поля файла

| Поле | Что это |
|---|---|
| `summary` | Описание проекта, 2–3 предложения. |
| `application` | `"after-effects"` или `"premiere-pro"`. По умолчанию берётся из категории проекта. Влияет на плитку программы и тексты. |
| `featured` | Ключевые функции. **Показываются только у featured‑проектов.** |
| `showFeatured` | `true` — показать блок `featured` и у обычного проекта. |
| `standard` | Функции, общие для всех проектов AE / Premiere Pro. |
| `extra` | Ваши дополнительные функции для конкретного проекта. |
| `included` | Категории сцен и их фото‑превью. |
| `tags` | Теги внизу. По умолчанию — теги проекта из каталога. |

### Значение каждой функции

У каждой функции в `featured` и `standard` значение может быть:

- `true` — показать со стандартным текстом;
- `false` — скрыть (если строку просто удалить, функция покажется со стандартным текстом);
- строка — только для `elements`: число на большой плитке, например `"750+"`;
- объект — свой текст: `{ "title": "…", "text": "…" }`. Можно также поменять `icon`, `size`, `tone`, `value`, `tag`.

### Ключевые функции (`featured`, только для featured‑проектов)

| Ключ | Плитка | Стандартный текст |
|---|---|---|
| `motionbro` | крупная, с иконкой | Works with MotionBro |
| `autoResize` | средняя, с иконкой и анимацией рамки | Auto-resize — сцены подстраиваются под размер композиции |
| `elements` | высокая, огромное число | `750+` ready-made elements (по умолчанию — сумма сцен из `included`) |
| `durationControl` | крупная, с анимированным таймлайном | Duration control — тянете слой на таймлайне, анимация подстраивается |
| `freeUpdates` | маленькая плашка | Free updates |
| `lifetimeLicense` | маленькая плашка | Lifetime license |
| `support` | маленькая плашка | Author support |

### Функции для всех проектов (`standard`)

| Ключ | Плитка | Стандартный текст |
|---|---|---|
| `app` | крупная, иконка Ae / Pr и версия | Works with After Effects (или Premiere Pro) **2024+**. Версию меняйте так: `"app": { "value": "2023+" }` |
| `controlsPanel` | средняя, с иконкой | Controls panel — основные настройки вынесены отдельно |
| `autoTextResize` | средняя, с иконкой | Auto text-boxes — рамка подстраивается под длину текста (скрипты) |
| `videoTutorial` | средняя, с иконкой | Video tutorial included |
| `freeFonts` | маленькая плашка | Free fonts — ссылки внутри проекта |
| `expressions` | маленькая плашка | Universal expressions — без ошибок в любой языковой версии |
| `structure` | маленькая плашка | Light & well organized — лёгкие эффекты, без тяжёлых файлов |

Для проектов категорий Plugins, Presets, DaVinci, Sound FX стандартные функции не показываются (они про AE/PR). Если нужно — укажите `"application"` или добавьте свои функции в `extra`.

### Свои функции (`extra`)

```json
"extra": [
  { "size": "lg", "icon": "bolt", "tone": "lime", "title": "Render in minutes", "text": "Optimized for fast previews." },
  { "size": "md", "icon": "music", "tone": "orchid", "title": "Music included", "text": "Licensed soundtrack inside." },
  { "size": "sm", "icon": "palette", "title": "Color presets", "text": "12 palettes" }
]
```

- `tone` (цвет мягкой рамки вокруг иконки): `ember` (персиковый), `lime` (лаймовый), `ice` (голубой), `orchid` (розово‑фиолетовый), `steel` (серый).
- `tag` — короткая метка в правом верхнем углу блока (например, `"Timing"`). Для своих фич по умолчанию — «Highlight».
- `size`: `lg` и `md` — большие светлые блоки (одинаковой ширины, растягиваются по высоте под текст), `sm` — компактная карточка с иконкой.
- `icon`: `after-effects`, `premiere-pro`, `motionbro`, `resize`, `timeline`, `refresh`, `infinity`, `support`, `sliders`, `textbox`, `play`, `font`, `code`, `feather`, `sparkle`, `music`, `palette`, `bolt`, `globe`, `layers`, `check`, `star`, `phone`, `cube`, `monitor`. Можно без иконки — тогда она подбирается по смыслу названия (телефон, 3D, цвет, звук, текст…), иначе `sparkle`.

**Сетка:** большие блоки сами раскладываются по 2–4 в ряд в зависимости от ширины экрана, маленькие (`sm`) идут отдельной сеткой под ними.

## Что включено (`included`)

Каждая категория — одна вкладка с количеством сцен. При выборе вкладки её сцены раскладываются на 3 ряда (на экране по 5 превью в ряду, остальные — прокруткой влево‑вправо). Показывается до 60 превью на категорию.

Два способа указать картинки:

1. **Папка с пронумерованными файлами** (удобнее всего):
   ```json
   { "title": "Typography", "count": 50, "folder": "/media/my-slug/scenes/typography", "ext": "jpg" }
   ```
   Положите файлы в `public/media/my-slug/scenes/typography/` с именами `01.jpg`, `02.jpg`, … `50.jpg` (если сцен больше 99 — `001.jpg`, `002.jpg`, …).
2. **Список файлов**:
   ```json
   { "title": "Lower thirds", "images": ["/media/my-slug/scenes/lt-01.jpg", "/media/my-slug/scenes/lt-02.jpg"] }
   ```
   `count` можно не указывать — посчитается по списку. Можно указать больше, чем картинок (например, 50 сцен, а превью только 20).

Без картинок (`{ "title": "Typography", "count": 50 }`) показываются цветные заглушки.

**Фото‑превью сцен:** 16:9, 640×360 px, JPG 70–80% (или WebP), до 60 КБ каждое. Номер сцены сайт подписывает сам.

## Проверка

После правки JSON обновите страницу проекта. Если файл сломан (лишняя запятая, нет кавычек), сборка сайта упадёт с ошибкой — проверьте файл любым JSON‑валидатором.
